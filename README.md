# Remote Interaction · 원격 상호작용

버튼·레버 등에 **아이템 없이 수신기를 붙이고**, 모드 창이나 키를 누르는 동안 나타나는 빠른 창에서 조작하는 Minecraft 모드입니다.

## 설치

- Minecraft Java Edition **26.2**, Java **25 이상**
- Fabric Loader **0.19.5 이상**, Fabric API **0.160.0+26.2**
- `remote-interaction-0.5.0.jar`와 Fabric API를 `mods` 폴더에 넣으세요.
- 멀티플레이는 **서버와 클라이언트 모두 같은 버전**을 설치해야 합니다. 싱글플레이는 게임에 설치하면 됩니다.
- Mod Menu는 선택 사항입니다. 모드 목록의 설정 버튼으로 모드 창을 열 수 있습니다.

`-sources.jar`는 설치용이 아닙니다. 이전 Remote Interaction JAR와 새 JAR를 함께 넣지 마세요.
다른 Minecraft 버전, Forge/NeoForge, Bedrock은 지원하지 않습니다.

## 시작하기

1. **`/ri`** 또는 **`/remoteinteraction`**으로 모드 창을 엽니다.
2. **수신기 붙이기**를 누른 뒤, 가까운 지원 블록을 **우클릭**합니다.
3. 붙이기 모드에서는 블록이 작동하거나 손의 아이템이 사용되지 않고 수신기만 등록됩니다. 별도 아이템·재료·조합법이 없습니다.
   부착에 사용한 우클릭을 계속 누르고 있어도 작동하지 않습니다. 손을 뗀 뒤 새로 누르면 일반 상호작용이 가능합니다.
4. 붙이기를 취소하려면 Esc 또는 붙이기 단축키를 다시 누르세요.
5. 모드 창에서 등록된 수신기를 작동시키거나 이름을 바꾸고 제거할 수 있습니다.
6. **전체 제거**를 누른 뒤 확인하면 **이 월드의 모든 차원에 등록한 본인 수신기**와 빠른 슬롯 연결이 삭제됩니다.
   검색으로 가려진 수신기, 청크가 로드되지 않은 수신기, 연결이 끊긴 수신기도 포함됩니다. 취소하면 유지됩니다.
   실제 블록·아이템·다른 플레이어의 수신기는 제거하지 않습니다.

수신기는 블록에 저장되는 부착 정보이며 별도 블록 공간을 차지하지 않습니다.
소유자의 화면에는 64블록 이내의 수신기 블록을 감싸는 **1×1×1 정육면체 윤곽**이 표시됩니다.
레버·버튼의 작은 모양이나 방향·켜짐 상태와 관계없이 블록 한 칸의 영역을 표시합니다. 벽 뒤를 투시하지 않습니다.

## 수신기 표시 설정

**`/ri` → 표시 설정**에서 모든 수신기의 윤곽 스타일을 조절합니다.

- **색상:** 색상 팔레트 또는 빨강·초록·파랑 슬라이더로 원하는 색을 만듭니다.
- **투명도:** 0~100%. 0%는 완전히 보이고 100%는 표시를 숨깁니다.
- **선 두께:** 1.0~6.0px, 0.1px 단위로 조절합니다.
- 미리보기와 월드 표시에 바로 반영됩니다. **저장**하면 유지되고, **취소·Esc**는 이전 설정으로 돌아갑니다.
- **기본 표시**는 청록색, 투명도 0%, 선 두께 2.5px입니다.

설정은 클라이언트의 `config/remote-interaction-markers.json`에 저장됩니다. 수신기 등록·슬롯과 다른 플레이어의 표시는 변경하지 않습니다.

## 단축키

**모든 단축키의 기본값은 미지정**입니다. 모드 창의 **단축키 설정**에서 아래 세 기능을 지정합니다.

| 기능 | 동작 |
| --- | --- |
| 모드 창 열기 | 관리 창 열기 |
| 수신기 붙이기 | 부착 대기 시작 / 취소 |
| 빠른 상호작용 | 키를 누르는 동안 빠른 창 표시 |

설정할 항목을 누르고 키를 입력하세요. **Shift + R**, **Ctrl + R**, **Ctrl + Alt + R** 등
Shift·Ctrl·Alt·Super와 일반 키의 조합을 지원합니다. 보조키만 누르면 다음 일반 키 입력을 기다립니다.
설정 중 Esc를 누르거나 **해제**를 누르면 미지정으로 돌아갑니다. 동일한 조합을 두 기능에 중복 지정할 수 없습니다.

입력한 조합과 일치할 때만 작동합니다. 예를 들어 Shift + R은 R만 눌러서는 작동하지 않습니다.
채팅·인벤토리·다른 창에서 입력 중에는 단축키로 창이 열리지 않습니다.
다른 모드 또는 게임 기능이 사용하는 키를 지정하면 해당 조합에서는 Remote Interaction이 우선할 수 있습니다.
설정은 `config/remote-interaction-keys.json`에 저장됩니다.

## 빠른 상호작용

모드 창의 **빠른 목록 설정**에는 수신기가 목록으로 표시됩니다. **각 수신기 아래의 1~9번 체크박스**에서 넣을 슬롯을 선택하거나 해제합니다.

- **9개 슬롯**을 제공하며 빈 슬롯은 빠른 창에 표시하지 않습니다.
- 한 슬롯에 수신기를 여러 개 넣을 수 있습니다. 한 수신기를 여러 슬롯에 넣는 것도 가능합니다.
- 선택은 서버 월드에 저장되어 재접속 후에도 유지됩니다. 다른 플레이어·다른 월드와 섞이지 않습니다.
- 빠른 키를 **누르고 있으면 시선이 고정되고 마우스 커서가 풀립니다**. 채팅창처럼 게임 자체는 계속 진행됩니다.
- 화면에는 수신기 **이름과 현재 블록 상태**만 표시합니다. 이름·상태 영역 전체가 버튼입니다.
- 같은 슬롯의 영역을 클릭하면 그 슬롯에 속한 수신기를 **한 번씩 함께 작동**시킵니다.
- 사용할 수 없는 수신기는 상태를 표시하고 건너뜁니다. 나머지 사용 가능한 수신기는 작동합니다.
- 키나 필수 보조키를 놓으면 즉시 닫히고 마우스로 시점을 움직일 수 있습니다. Esc로도 닫을 수 있습니다.
- 키를 누르고 있기만 해서는 반복 작동하지 않습니다. 목록이 화면보다 길면 마우스 휠로 이동합니다.

예: 현관 레버와 조명 레버를 슬롯 1에, 종을 슬롯 2에 넣으면 빠른 창의 첫 영역은 두 레버를 함께 조작하고 둘째 영역은 종을 울립니다.
여러 레버의 조작은 각각 현재 상태를 뒤집는 동작이며, 서로 다른 초기 상태를 강제로 같은 상태로 맞추는 기능은 아닙니다.

### 빠른 창 위치·크기

**빠른 목록 설정 → 빠른 창 배치**를 엽니다. 미리보기 안을 드래그해 위치를 옮기고,
**오른쪽 아래의 노란 모서리**를 드래그해 가로·세로 크기를 조절한 뒤 **저장**하세요.
미리보기에서는 실제 블록을 작동시키지 않습니다. 기본 배치로 되돌릴 수 있고, 취소·Esc는 변경을 저장하지 않습니다.

창의 크기는 목록이 보이는 영역입니다. 글자 크기는 Minecraft의 GUI 배율을 따릅니다.
내용이 창보다 길면 그 창 위에서 마우스 휠로 스크롤합니다. 실제 빠른 창에는 배치 편집 버튼을 표시하지 않습니다.
위치·크기는 `config/remote-interaction-window.json`에 저장됩니다. 해상도·GUI 배율이 달라져도
상대적인 배치를 유지하며 화면 밖으로 나가지 않도록 조정합니다. 기존 수신기와 슬롯 지정은 그대로 유지됩니다.

## 지원 블록

| 블록 | 원격 동작 |
| --- | --- |
| 버튼 | 누른 뒤 바닐라 시간에 자동 복귀 |
| 레버 | 켜기 / 끄기 |
| 손으로 열 수 있는 문·다락문·울타리 문 | 열기 / 닫기 |
| 중계기 | 지연 단계 변경 |
| 비교기 | 비교 / 감산 모드 전환 |
| 소리 블록 | 음높이 변경 |
| 종 | 울리기 |
| 햇빛 감지기 | 일반 / 반전 모드 전환 |

철 문·철 다락문, 보관함·작업 화면, 아이템 투입이 필요한 블록, 엔티티는 지원하지 않습니다.
바닐라 상호작용을 사용하므로 잠긴 중계기 등은 상황에 따라 변하지 않을 수 있습니다.

## 범위와 저장

한 블록에 수신기 1개, 한 플레이어당 최대 128개를 등록합니다. 부착은 일반 상호작용 거리 안에서
실제로 바라보고 있는 블록만 허용합니다. 원격 작동은 **본인 소유, 같은 차원, 로드된 청크**를 조건으로 하며 거리 제한은 없습니다.
청크를 강제로 로드하지 않습니다. 관전자·모험 모드에서의 변경은 허용하지 않습니다.

수신기의 이름·위치·소유권·빠른 슬롯은 서버의 월드 데이터에 저장됩니다.
블록이 파괴·교체·피스톤 이동되면 연결이 끊깁니다. 같은 곳에 같은 블록을 놓아도 자동 재연결하지 않으며 목록에서 제거할 수 있습니다.
기본 보호 검사 및 Fabric `UseBlockCallback` 거부 응답을 확인합니다. 다른 방식으로 작동하는 보호 플러그인은 별도 호환 확인이 필요합니다.

0.1.0의 등록된 수신기는 유지되며 빠른 슬롯은 미선택으로 시작합니다. 기존 수신기 아이템·조합법과 아이템 반환 동작은 제거했습니다.

## 개발 및 검증

```text
./gradlew build
./gradlew runClientGameTest
```

Windows에서는 `gradlew.bat`을 사용합니다. 게임 테스트는 별도 임시 월드에서 실행합니다.
기본 미지정, 복합키 설정·저장·충돌 방지, 맨손 및 아이템을 든 상태의 부착, 빠른 창의 자유 마우스와 시점 고정,
부착 입력을 길게 누른 동안의 작동 방지와 다음 입력 복구, 전체 제거 확인·취소·소유자 범위·재접속 저장,
키/보조키 해제, 여러 수신기의 동시 작동, 수신기별 슬롯 체크·해제, 창 이동·크기·저장·취소·스크롤,
슬롯 저장·재접속, 정육면체 표시·색상·투명도·선 두께·설정 복원, 소유권·보호·청크 검사 등을 검증합니다.
GitHub Actions에서도 빌드와 게임 테스트를 실행하며 설치 JAR와 화면 증거를 아티팩트로 제공합니다.
