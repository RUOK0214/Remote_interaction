# Remote Interaction · 원격 상호작용

버튼·레버 등에 **수신기를 붙이고 하나의 창에서 원격으로 조작**하는 Minecraft 모드입니다.
각 수신기에 이름을 붙여 문, 조명, 레드스톤 회로를 구분할 수 있습니다.

## 실행 환경

- Minecraft Java Edition **26.2**
- Fabric Loader **0.19.5 이상**
- Fabric API **0.160.0+26.2**
- Java **25 이상**
- **클라이언트와 서버 모두 설치**해야 합니다. 싱글플레이는 클라이언트에 설치하면 됩니다.
- Mod Menu는 선택 사항입니다. 설치하면 모드 목록의 설정 버튼으로 조작 창을 열 수 있습니다.

`remote-interaction-0.1.0.jar`와 해당 버전의 Fabric API를 게임/서버의 `mods` 폴더에 넣으세요.
`-sources.jar`는 개발용 소스이며 설치용이 아닙니다. 다른 Minecraft 버전, Forge/NeoForge, Bedrock은 지원하지 않습니다.

## 사용 방법

1. 아래 조합법으로 **원격 수신기 2개**를 만듭니다. 크리에이티브에서는 레드스톤 탭에서 찾을 수 있습니다.
2. 수신기를 들고 지원 블록을 **우클릭**합니다. 수신기 1개가 소비되며, 그 블록 자체는 작동하지 않습니다.
3. **R 키** 또는 **`/ri`**, **`/remoteinteraction`**으로 조작 창을 엽니다.
4. 목록의 **작동**을 누르면 실제 서버에서 해당 블록을 한 번 우클릭한 것처럼 작동합니다.
5. 목록의 이름을 선택하면 **이름 변경** 또는 **수신기 회수**를 할 수 있습니다.

| 철 주괴 | 구리 주괴 | 철 주괴 |
| --- | --- | --- |
| 레드스톤 | 네더 석영 | 레드스톤 |
| 철 주괴 | 구리 주괴 | 철 주괴 |

명령어로 받기: `/give @s remote_interaction:receiver`

설정 → 조작 → 원격 상호작용에서 R 키를 변경할 수 있습니다. 이름과 좌표로 목록을 검색하고 페이지를 넘길 수 있습니다.
수신기 이름은 최대 32자이며 비워 두면 현재 언어의 블록 이름을 사용합니다. 한국어와 영어를 제공합니다.

## 지원 블록

| 블록 | 원격 동작 |
| --- | --- |
| 버튼 | 누르기, 이후 기본 시간에 자동 복귀 |
| 레버 | 켜기 / 끄기 |
| 손으로 열 수 있는 문·다락문·울타리 문 | 열기 / 닫기 |
| 중계기 | 지연 단계 변경 |
| 비교기 | 비교 / 감산 모드 전환 |
| 소리 블록 | 음높이 조절 |
| 종 | 울리기 |
| 햇빛 감지기 | 일반 / 반전 모드 전환 |

철 문·철 다락문, 상자·화로 등 보관함/작업 화면, 아이템 투입이 필요한 블록, 엔티티는 지원하지 않습니다.
바닐라 동작을 사용하므로 잠긴 중계기 등은 상황에 따라 변하지 않을 수 있습니다.

## 수신기와 연결 범위

- 수신기는 **대상 블록에 저장되는 부착 정보**입니다. 별도 블록 공간을 차지하지 않습니다.
- 붙인 위치에는 본인에게만 보이는 작은 청록색 수신기 윤곽이 표시됩니다(64블록 이내, 벽을 투시하지 않음).
- 수신기 목록·이름·소유권은 **서버의 월드 데이터**에 저장되어 재접속과 서버 재시작 후에도 유지됩니다.
- 한 블록에는 수신기 1개만, 한 플레이어는 최대 128개까지 등록합니다.
- **본인 소유, 현재 차원, 이미 로드된 청크**에서만 원격으로 작동합니다. 거리 제한은 없습니다.
- 모드가 청크를 강제로 로드하거나 다른 차원의 블록을 작동시키지는 않습니다.
- 대상이 파괴·교체·피스톤 이동되면 연결을 잃습니다. 같은 곳에 같은 블록을 놓아도 자동 재연결하지 않습니다.
- 연결을 잃거나 청크가 로드되지 않아도 창에서 회수할 수 있습니다. 생존에서 사용한 수신기만 반환합니다.
- 크리에이티브 부착은 아이템을 소비하지 않으므로 회수 시 추가 아이템이 생기지 않습니다.
- 인벤토리가 가득 차면 회수한 아이템은 플레이어 위치에 떨어집니다.

관전자·모험 모드의 조작은 막으며, 서버의 기본 보호 검사와 Fabric `UseBlockCallback`의 거부 응답을 적용합니다.
별도 보호 플러그인이 다른 방식으로 상호작용을 제한하는 서버에서는 해당 플러그인과의 호환 확인이 필요합니다.

## 개발 및 검증

```text
./gradlew build
./gradlew runClientGameTest
```

Windows에서는 `gradlew.bat`을 사용합니다. 테스트는 별도 임시 월드를 만들며 실제 사용자 월드를 사용하지 않습니다.
게임 테스트는 부착 시 아이템 소비, 레버·버튼 원격 동작, 추가 지원 블록, 조합법, 소유권 및 보호 검사,
다른 차원/미로드 청크 제한, 대상 파괴, 중복 환불 방지, 이름 변경, 한국어 작은 화면, 월드 저장·재접속을 확인합니다.

설치 파일: `build/libs/remote-interaction-0.1.0.jar`

GitHub Actions에서도 빌드와 게임 테스트를 실행하고 설치 파일 및 테스트 화면을 아티팩트로 제공합니다.
